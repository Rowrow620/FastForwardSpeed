# Fast-Forward Speed Multipliers for Lobotomy Corporation

Zooming is fun.
A mod for Lobotomy Corporation that upgrades in-game speed buttons to faster multipliers.

---

## Speed Multiplier Variants

This repository contains two mod variants:

### 1. `FastForwardSpeed` (1x, 4x, 8x)
Modifies the 3 in-game speed buttons to:
- **Button 1 (`>`)**: 1x (Normal Speed)
- **Button 2 (`>>`)**: **4x Speed**
- **Button 3 (`>>>`)**: **8x Speed**

### 2. `EvenFasterForwardSpeed` (1x, 8x, 16x)
Modifies the 3 in-game speed buttons to:
- **Button 1 (`>`)**: 1x (Normal Speed)
- **Button 2 (`>>`)**: **8x Speed**
- **Button 3 (`>>>`)**: **16x Speed**

---

## Installation

### Option 1: Via Lobotomy Mod Manager (LMM)
1. Open `LobotomyModManager.exe`.
2. Click **Add LocalMod** and select your preferred `.zip` release (`FastForwardSpeed-v1.0.0.zip` or `EvenFasterForwardSpeed-v1.0.0.zip`).
3. Ensure the mod is checked in your mod list, then click **Start Game**.

### Option 2: Manual Installation
1. Extract your preferred mod directory (`FastForwardSpeed` or `EvenFasterForwardSpeed`) into your game folder:
   `LobotomyCorp_Data\BaseMods\`
2. Launch Lobotomy Corporation.
